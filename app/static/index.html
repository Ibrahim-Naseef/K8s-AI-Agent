How it works

Cheap rules first, AI only when it is needed.

1

Scan

Rule-based pre-check finds CrashLoops, image errors, OOM kills, pending pods, quota failures and Services with no endpoints. Healthy namespaces cost nothing.
2

Investigate

The LLM picks read-only tools (describe, logs, events, services, PVCs, nodes) and follows the evidence for up to 8 steps.
3

Diagnose

You get a root cause, evidence, confidence with reasoning and affected objects. Secrets are redacted.
4

Fix

Copy-ready kubectl commands and prevention tips. If the model gives none, a built-in knowledge base fills them in.

    Safety

    Read-only ClusterRole. No Secrets access and no write verbs.
    Namespaces are auto-discovered, system ones hidden. Localhost-only by default; set APP_TOKEN to allow remote access.
    Logs are treated as untrusted data. Redaction runs on everything sent out or stored.
